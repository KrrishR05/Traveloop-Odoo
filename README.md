# TRAVELOOP 🌍✈️

## Smart Travel Planning Platform

Traveloop is a modern full-stack travel planning platform that helps users discover destinations, create itineraries, manage budgets, organize trips, and share travel experiences — all in one seamless ecosystem.

Built with a premium modern UI/UX approach, Traveloop combines intelligent planning tools, analytics, and community-driven travel experiences into one platform.

---

# 🚀 Features

- Google & OTP-based Authentication
- Destination Discovery System
- Smart Trip & Itinerary Planner
- Budget Analytics Dashboard
- Packing Checklist Manager
- Travel Journal
- Community Travel Feed
- Multi-Currency Budget Support
- Responsive Modern UI
